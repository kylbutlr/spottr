Spottr support

Get back to capturing.

Most Spottr problems come from Chrome restricting the current page, the page changing during capture, or the local browser profile running short on storage.

Capture will not start

  • Open a normal http or https webpage, then try again.
  • Chrome blocks extensions on chrome:// pages, the Chrome Web Store, browser UI, and some built-in viewers.
  • For a local file:// page, serve the file over localhost. Spottr does not request file access.
  • Reload a page that was already open when Spottr was installed, then retry.

The screenshot is missing or wrong

  • Keep the target tab active until the note composer appears.
  • Spottr captures only the visible viewport, not a full scrolling page.
  • If the page zoom, viewport, or browser window changes mid-capture, cancel with Escape and start again.

A note will not save

  • Add a note description and select a valid project and QA session.
  • Delete unneeded screenshots if the Chrome profile is low on storage.
  • Copy or export important sessions before clearing data or reinstalling.

Copy or export failed

  • If Copy JSON fails, use Export JSON.
  • If Export JSON fails, use Copy JSON and paste into a local text file.
  • Large screenshot-backed sessions produce large JSON files. Split the review into smaller QA sessions if needed.

Keyboard shortcuts

Open Spottr settings, then choose Configure shortcuts. Chrome manages shortcut conflicts, so a key combination already used by another extension may need to be changed.

Before requesting support

Record the Spottr version, Chrome version, page type, steps to reproduce, and the exact on-screen message. Do not send a real export or screenshot unless you have reviewed it for private URLs, tokens, customer data, and other sensitive content.

Public beta support is provided through the Support link on the Chrome Web Store listing. A permanent public support URL must be configured before publication.
