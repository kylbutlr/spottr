Spottr public beta

Capture visual QA without the account overhead.

Spottr turns a selected part of any regular webpage into a screenshot-backed note with the context another person needs to reproduce it.

Your evidence stays in this Chrome profile. Spottr has no account, server, analytics, or cloud sync. Nothing leaves the browser unless you choose Copy JSON or Export JSON.

Quick start

Your first QA session

  1. Open a webpage

    Use a normal http or https page. Chrome blocks extension access on settings, Web Store, and other restricted pages.

  2. Capture the issue

    Open Spottr, choose Capture area, then drag a rectangle around the visual problem. Press Escape to cancel.

  3. Describe what matters

    Add a short observation, confirm the project and QA session, then save. Use Add text-only note when a screenshot is not useful.

  4. Organize the pass

    Keep related notes in one QA session. Create another session for a different review, viewport, or retest.

  5. Export the evidence

    Copy or download the active session as JSON. Review the file before sharing because it can contain page URLs and screenshots.

Evidence boundary

What a saved note contains

DataWhy Spottr records it
Your noteThe issue description you type.
Selected screenshotA WebP crop of the visible viewport, only for Capture area notes.
Page contextRaw and normalized URL, page title, viewport size, device pixel ratio, scroll position, and selection coordinates.
OrganizationProject and QA session names, local identifiers, and capture time.

Capture carefully. A selected screenshot, page title, URL, or note can contain confidential information. Spottr does not inspect or redact your evidence for you.
